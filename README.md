# YUAG Alt-Text Demo

**Live site:** https://yale-ch.github.io/yuag-alt-text-demo/

A test viewer for AI-generated alt-text for Yale University Art Gallery images. The YCBA version is [yale-ch/chai-alt-text](https://github.com/yale-ch/chai-alt-text).

> **For testing only.** The descriptions were generated by AI as an experiment. They are not official or verified alt-text, and nobody has reviewed them.

## How the alt-text is made

The alt-text comes from a [chai-engine](https://github.com/yale-ch/chai-engine) workflow, [`workflow/workflow-alt-text-yuag.json`](workflow/workflow-alt-text-yuag.json). It contains no project-specific Python. For each object in a CSV of IIIF manifest URLs (`objectid,title,manifest`), the workflow:

1. Fetches the object's IIIF manifest (`UrlJsonProvider`).
2. Reads the **Classification** and **Medium** from the manifest's metadata (`JsonXpathExtractor`).
3. Downloads the first image, scaled to fit 1600×1600 (`IIIFDirFileProvider`, `size: "!1600,1600"`).
4. Asks Gemini 3.1 Flash-Lite for 4–6 plain sentences that open with the kind of object, for example "A marble relief of …". The fixed rules go in the system instruction. The object's classification and medium go at the end of the prompt.
5. Writes one CHAI-TEA RESULT row per object to a JSON-Lines file (`JsonLinesStorage`). Each row records the call's token usage, duration and **cost in USD**.

Run it from a chai-engine checkout, with the CSV at `inputs/alt_text_yuag/objects.csv`:

```bash
python scripts/run_workflow.py path/to/workflow-alt-text-yuag.json
```

## Building the site's data

`scripts/build_site_data.py` takes the run's JSON-Lines file and the CSV. It joins each row to its object's manifest (department, classification, medium, image) and writes `docs/data/runs/<id>.json`, plus an entry in `docs/data/runs.json` that holds the run's total cost and tokens. It needs only the Python standard library.

```bash
python scripts/build_site_data.py results/alt_text_yuag/run.jsonl inputs/alt_text_yuag/objects.csv \
  --id 20261028-full-6432 --label "Full run — 6,432 objects" --model gemini-3.1-flash-lite
```

The site is static (`docs/`, served by GitHub Pages from `main`). To view it locally, run `python -m http.server --directory docs`.
